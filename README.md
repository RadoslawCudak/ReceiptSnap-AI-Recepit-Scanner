# Azure AI Receipt Scanner 


### Co robi ten projekt?
- Wykrywa nowe zdjęcia w Azure Blob Storage.
- Wykorzystuje **Azure Document Intelligence** (AI) do odczytu danych z paragonów.
- Zapisuje wyniki (Sklep, Kwota, Data) do **Azure Table Storage**.
- Wykorzystuje **Managed Identity** dla bezpiecznej komunikacji.

### Technologie
- Python 3.12
- Azure Functions (Serverless)
